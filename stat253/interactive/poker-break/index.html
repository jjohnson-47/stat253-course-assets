🧮 The Mathematical Foundation

Combinatorial Probability Formula

For any poker hand type:

$$P(\text{Hand Type}) = \frac{\text{Number of ways to make that hand}}{\binom{52}{5}} = \frac{\text{Favorable outcomes}}{2,598,960}$$

Each hand probability is computed using exact combinatorial analysis

Examples of Hand Calculations

  • Royal Flush: Only 4 possible (one per suit) → P = 4/2,598,960 ≈ 0.000154%
  • Straight Flush: 36 possible (9 per suit, excluding royal) → P ≈ 0.00139%
  • Four of a Kind: $13 \times \binom{4}{4} \times \binom{48}{1}$ = 624 ways → P ≈ 0.024%
  • Full House: $13 \times \binom{4}{3} \times 12 \times \binom{4}{2}$ = 3,744 ways → P ≈ 0.144%
